# RadioRubben-robot
Radio Rubben – Robåt utvikler RR Robot, en digital redaksjonsmotor for fotball, lokale nyheter, trafikk, vær, arrangementer og radiomanus. Systemet skal hente og strukturere data fra sikre kilder, bruke AI til bearbeiding og støtte publisering til RadioRubben.no, studio.radiorubben.no og sosiale medier.
